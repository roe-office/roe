# roe_symbols

- ROESymbols.ttf：ROE 自绘的项目符号字体，由 tools/gen_roe_symbols.py 生成，权属为本项目。
- opens___.ttf：LibreOffice 的 OpenSymbol 字体，复制自本机 LibreOffice 安装目录。
  许可证未确认：字体文件和源码树里都没有许可证条款；2012 年 LibreOffice 开发者邮件列表中
  有开发者个人意见称其为 LGPLv3，不是官方声明。正式发布前必须确认，
  或改回 ROESymbols.ttf（tile.rs 标签字体名换回 "ROE Symbols" 即可）。
